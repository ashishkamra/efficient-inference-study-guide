Glossary

Short definitions in the survey’s own terms. Search by name or meaning.

25 of 25 terms

Prefill
The compute-bound forward pass over the prompt that fills the KV cache. Sets TTFT together with queueing.
Taught inLesson 01Lesson 02Lesson 03Lesson 07
Decode
Token-at-a-time generation. At small batch, memory-bandwidth-bound. Sets TPOT.
Taught inLesson 01Lesson 02Lesson 03
Operational intensity
FLOPs performed divided by bytes moved from main memory. Compared with the ridge point π/β.
Taught inLesson 02
Ridge point
I_ridge = π/β. The lowest intensity that can saturate peak compute. Modern accelerators: hundreds of FLOPs/byte.
Taught inLesson 02
Roofline
The bound P ≤ min(π, β·OI). Below the ridge, memory bandwidth binds; at or above it, the compute ceiling does.
Taught inLesson 02
MQA
Multi-query attention. One KV head shared by every query head. The smallest cache in the MHA–GQA–MQA family, with the largest recall risk.
Taught inLesson 03Lesson 04
KV cache
Stored keys and values so decode does not recompute history. Footprint is equation (5). The survey’s full-stack ledger.
Taught inLesson 01Lesson 03Lesson 04Lesson 08
GQA
Grouped-query attention. Several query heads share one KV head group. The usual production point between MHA and MQA.
Taught inLesson 03Lesson 04
MLA
Multi-head latent attention. Cache a low-rank latent c_t and rebuild K and V. Breaks the factor-of-two in equation (5).
Taught inLesson 03Lesson 04
Mamba
Selective state-space model. Fixed-size recurrent state, input-dependent transitions, O(1) decode, parallel scan in training.
Taught inLesson 04
Speculative decoding
Draft γ tokens, verify with one target forward, reject so the output distribution matches the target. Lossless. Speedup tracks τ.
Taught inLesson 05
τ
Mean accepted tokens per speculation step. End-to-end speedup is about τ minus verification overhead.
Taught inLesson 05
Goodput
Throughput that actually meets a latency SLO. DistServe’s objective, not raw tokens/s.
Taught inLesson 02Lesson 07
TTFT / TPOT
Time to first token (prefill, queueing). Time per output token (decode bandwidth and KV size).
Taught inLesson 01Lesson 02
W4A8
4-bit weights, 8-bit activations. Atom and QServe. A current production quantization point, kernel-co-designed.
Taught inLesson 06Lesson 08
KIVI
Asymmetric KV quantization: per-channel keys, per-token values, about 2 bits, no extra tuning.
Taught inLesson 06
2:4 sparsity
Exactly 2 of every 4 weights zero. The N:M pattern Sparse Tensor Cores run at about 2× dense throughput.
Taught inLesson 06
On-policy distillation
Train the student on its own samples to match the teacher. Closes the train–inference mismatch. GKD, DistiLLM.
Taught inLesson 06
PagedAttention
KV memory in fixed pages (typically 16 tokens) with a block table, instead of one contiguous max-length reservation.
Taught inLesson 07
FlashAttention
Exact softmax attention tiled through SRAM, avoiding the T×T HBM write. IO-aware, not an approximation.
Taught inLesson 07
Eviction
Drop or sparsify cached KV entries (H2O, StreamingLLM, sliding windows). Shrinks the effective sequence length s; the history is gone, so recall is not free.
Taught inLesson 04Lesson 03
Continuous batching
Admit and retire requests at each decode step. Removes head-of-line blocking. Orca.
Taught inLesson 03Lesson 07
RadixAttention
Prefix KV stored in a radix tree so shared system prompts are not recomputed. SGLang.
Taught inLesson 07
Disaggregation
Prefill pool and decode pool on separate hardware, often different GPU shapes, with KV shipped between them.
Taught inLesson 07Lesson 08
Chunked prefill
Slice a long prefill and interleave it with decode so one pool can protect TPOT. Sarathi-Serve.
